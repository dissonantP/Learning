# Repository conventions

This repository is organized as a browsable learning knowledge base.

- The root `README.md` serves as the main index for the repository.
- Each topic gets its own folder.
- Each topic folder has its own `README.md` as the entry point for that topic.
- A topic's `README.md` may link out to additional sub-documents within that topic folder as needed.
- Use the filename `README.md` specifically because GitHub's UI renders it automatically when viewing the repository root or navigating into a folder.
