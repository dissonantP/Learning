HydraFusion: runtime multi-model orchestration

GitHub’s research preview builds a plan, routes stages to different models, and uses draft/critique/revision or escalation to stronger models.

Why it matters: Model selection becomes part of the control loop rather than a fixed property of an agent.

Practical takeaway: Separate planner → worker → critic, and reserve stronger models for critique or escalation.

CapScope: capability-scoped subagents

Permissions live outside model context and can be scoped per worker rather than inherited globally.

Why it matters: A verifier can be read-only while a coding worker gets repository-write authority.

Practical takeaway: Make capabilities properties of the worker/tool gateway, not prompt instructions.

Source

MCP goes stateless

A recent MCP revision removes much of the protocol’s server-side session requirement.

Why it matters: Remote MCP becomes much easier to scale with ordinary stateless HTTP infrastructure.

Practical takeaway: Prefer stateless workers behind a normal load balancer unless persistent server state is genuinely required.

Source

Sandbox policy moves into the harness

GitHub Copilot for JetBrains now supports centrally managed filesystem, network, proxy, developer-tool, and Keychain policies, alongside agent logs and OpenTelemetry support.

Why it matters: Agent capability boundaries and observability are becoming first-class platform concerns.

Practical takeaway: Attach sandbox policy to agent identities/profiles rather than shell launchers.

Optimize task completion, not token count

GitHub argues that overly short tool results can increase total cost by causing more retries, turns, and redundant calls.

Why it matters: “Return as little as possible” is not necessarily the right MCP/tool-design strategy.

Practical takeaway: Measure cost per completed or verifier-passing task, not tokens per turn.

Source

ττ-Bench evaluates agents that build agents

The benchmark asks a developer agent to build and deploy a working customer-service agent against a realistic codebase and production-style constraints.

Why it matters: It evaluates the produced harness in operation rather than only grading patches.

Practical takeaway: Outer verifier loops should test artifacts in their real operating environment.

Source

MCP health needs semantic probes

Production measurements suggest many MCP endpoints are reachable while still failing tool delivery, schema, or protocol behavior.

Why it matters: HTTP 200 is a weak health signal for an agent tool server.

Practical takeaway: Run representative tool calls and validate response schemas as synthetic monitoring.
