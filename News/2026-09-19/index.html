Agent infrastructure · security

Skills are a new kind of supply chain

MalSkillBench makes a useful distinction: an agent skill is neither merely code nor merely prompt. It is a hybrid package of instructions, executable behavior and permissions—and scanners built for only one half miss the attacks that cross the boundary.

Agent infrastructure · production lessons

The control plane, not the chat log

Recent agent incidents and deployments point toward a more useful observability model: record what authority existed, what was exercised, and what crossed a boundary—not just what the model said.

Seven works turn abstractions—surveillance, toxic land, AIDS policy, state security, protest risk, media war and institutional authority—into objects or spaces a viewer has to negotiate.
